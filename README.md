🎯 Jogo de Adivinhação

Bem-vindo(a) ao meu projeto Jogo de Adivinhação!
Este é um mini game divertido e simples, feito com HTML, CSS e JavaScript puro, onde o jogador deve adivinhar um número aleatório entre 0 e 20.

🔍 Como funciona?

O jogo gera um número aleatório de 0 a 20 no início.

O jogador tem 5 tentativas para acertar.

A cada tentativa, o jogo dá dicas se o número é maior ou menor do que o palpite.

Ao acertar, uma mensagem de parabéns é exibida.

Ao errar todas as tentativas, o número correto é revelado.

É possível reiniciar o jogo a qualquer momento.

🛠️ Tecnologias utilizadas

HTML5

CSS3 (com design responsivo e estilizado)

JavaScript Vanilla
